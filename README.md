#  Análisis de Comparendos de Tránsito - Municipio de Chía

Proyecto de análisis de datos que procesa un dataset público de comparendos de tránsito utilizando **Python (pandas)** para limpieza y transformación, y **Power BI** para visualización interactiva y cálculo de métricas con **DAX**.

##  Objetivos del Proyecto
- Limpiar y estructurar datos crudos provenientes de la plataforma de Datos Abiertos Colombia.
- Generar columnas derivadas para análisis temporal (año, mes, día de la semana, trimestre).
- Diseñar un dashboard interactivo que responda preguntas clave sobre patrones de infracción y gestión de tránsito.

##  Tecnologías Utilizadas
| Herramienta | Uso |
|-------------|-----|
| Python 3.x | Limpieza, transformación y exportación de datos |
| Pandas | Manipulación de DataFrames y manejo de fechas |
| Jupyter Notebook | Entorno de desarrollo paso a paso |
| Power BI Desktop | Visualización, métricas DAX y dashboard interactivo |
